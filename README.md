# diet-app

신체 정보로 하루 목표 칼로리를 계산하고, 식사 기록과 냉장고 재료를 바탕으로 **다음에 무엇을 먹을지** 알려주는 식단 관리 웹앱.

기록에서 끝나는 식단 앱과 달리, 목표 칼로리라는 기준선을 먼저 세우고 모든 추천을 그 기준선과의 차이(잔여 칼로리)로 계산한다.

## 기능

| ID | 기능 | 내용 |
|---|---|---|
| F1 | 프로필 및 목표 설정 | BMR → TDEE → 목표 칼로리 (Mifflin-St Jeor), 탄단지 배분 |
| F2 | 하루 식단 기록 | 끼니별 기록, 누적 섭취량 집계 |
| F3 | 냉장고 재료 관리 | 재료 목록, 유통기한 임박 표시, (선택) 사진 인식 |
| F4 | 다음 식사 추천 | 잔여 칼로리를 남은 끼니로 배분해 음식 제안 |
| F5 | 재료 기반 레시피 추천 | 보유 재료 매칭률 + 유통기한 임박 가산점 |
| F6 | 일일 대시보드 | 목표 대비 진행률, 초과·부족 안내 |

## 기술 스택

Next.js (App Router) · TypeScript · Prisma + SQLite · Tailwind CSS · Vitest
