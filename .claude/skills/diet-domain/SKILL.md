# 식단앱 공통 도메인 계약

`기능명세서.md`를 코드로 옮길 때 **모든 기능이 공유하는 단일 진실 공급원**이다. F1~F7 스킬은 전부 이 문서를 전제로 한다. 여기 값과 다르게 구현하면 기능 간 숫자가 어긋난다.

원문 명세는 `기능명세서.md` 2장 「핵심 개념」(34~67행). 판단이 애매하면 원문을 먼저 읽는다.

## 용어

| 용어 | 뜻 | 결정 요소 |
|---|---|---|
| BMR | 기초대사량 | 키, 몸무게, 나이, 성별 |
| TDEE | 일일 총 소비 열량. **운동은 포함하지 않는다** | BMR × 활동계수 |
| 일일 조정량 | 목표 체중 도달을 위해 하루에 덜/더 먹어야 할 열량 | 목표 체중, 목표 기간 |
| 기본 목표 | 운동을 안 했을 때 하루 섭취 목표. 하루 동안 고정 | TDEE ∓ 일일 조정량 |
| 운동 소모 | 그날 운동으로 추가로 태운 열량 | 운동 종류·시간·체중 |
| 오늘 목표 | 실제로 오늘 먹을 수 있는 열량. **운동 기록마다 늘어난다** | 기본 목표 + 운동 소모 |
| 잔여 | 앞으로 더 먹을 수 있는 열량 | 오늘 목표 − 누적 섭취 |

## 핵심 항등식

```
오늘 목표 = 기본 목표 + 오늘 운동 소모 합계     (100% 반영 — 미결정 #8 확정)
잔여     = 오늘 목표 − 오늘 누적 섭취
```

잔여는 F5(식사 추천)와 F6(레시피 추천)의 입력이다. 추천 기능은 독립적이지 않고 F1의 기준선과 F3이 더한 여유분에 종속된다.

> **활동계수와 운동을 분리하는 이유** — 활동계수를 "주 3~5회 운동" 같은 운동 빈도로 정의하면 운동을 개별 기록할 때 같은 운동을 두 번 세게 된다. 이 앱에서 **활동계수는 운동을 제외한 일상 활동만** 나타내고, 운동은 전부 F3에서 그날그날 더한다. 활동 수준 선택 UI에는 반드시 안내 문구를 붙인다.

## 반올림 규칙 (중요 — 명세 수치를 재현하려면 반드시 이대로)

**단계적 반올림을 쓴다.** BMR·TDEE·일일 조정량을 **각각 정수로 반올림한 뒤** 기본 목표를 계산한다. 실수로 이어 계산하면 명세의 예시 값과 1 kcal씩 어긋난다.

```
BMR      = round(1698.75) = 1699
TDEE     = round(1698.75 × 1.2) = round(2038.5) = 2039
일일 조정량 = round(38500 ÷ 84) = round(458.33) = 458
기본 목표  = 2039 − 458 = 1581        ← 명세 값 ✓

(실수로 이어서 계산하면 2038.5 − 458.33 = 1580.17 → 1580 으로 어긋남 ✗)
```

- 반올림은 `Math.round` (0.5는 올림)
- 탄단지 그램도 각각 `Math.round`
- 운동 소모 kcal도 `Math.round` — `8.3 × 75 × 0.5 = 311.25 → 311`
- 주당 변화 속도만 **소수 2자리** — `5 ÷ 12 = 0.42`
- 매칭률은 소수 없이 백분율 정수

체지방 1kg           7,700 kcal      (감량·증량 모두 동일 — 미결정 #9 확정)

                    1.375 서서 일하거나 자주 걸음 (교사, 판매직)
                    1.55  하루 대부분 서거나 걷는 직업 (간호사, 요식업)
                    1.725 육체노동 (건설, 물류, 농업)
탄단지 비율          다이어트 40:30:30 / 유지 50:20:30 / 증량 50:25:25
열량 계수            탄수 4 kcal/g · 단백질 4 kcal/g · 지방 9 kcal/g

입력 허용 범위        나이 10~100세 · 키 100~250cm · 몸무게 30~300kg

## 날짜 규칙

- 하루의 경계는 **로컬 타임존 자정**. 날짜 키는 `YYYY-MM-DD` 문자열
- UTC로 저장했다가 로컬로 보여주면 자정 전후 기록이 다른 날로 새므로, **날짜 컬럼은 `date` 타입 문자열로 그대로 저장**한다
- 미래 날짜 기록은 거부, 과거 날짜 기록은 허용

## F1 미완료 상태 (F2·F3·F5·F7 공통)

프로필이 없으면 기본 목표를 알 수 없다. 이때는

- 식사·운동·재료 **기록은 허용**한다
- 잔여 칼로리·오늘 목표·진행률은 **표시하지 않는다** (0으로 표시하지 말 것)
- F5 식사 추천은 **사용 불가** — 프로필 설정으로 유도
- 운동 소모 칼로리는 체중이 없으면 계산할 수 없으므로, MET 경로는 막고 직접 입력 경로만 연다

## 표기 원칙

- 칼로리는 천 단위 콤마 (`1,581 kcal`)
- 목표 초과를 **경고로 표현하지 않는다.** 중립적 서술을 쓴다. 사용자가 기록을 회피하게 만들지 않는 것이 목적 (명세 398행)
- 계산 결과는 근거와 함께 노출한다. `MET 8.3 × 75kg × 0.5시간 = 311 kcal`, `기본 1,581 + 운동 311 = 1,892` 처럼 식을 보여준다
