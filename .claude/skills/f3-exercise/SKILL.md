# F3. 운동 기록 및 소모 칼로리 반영

명세 출처: `기능명세서.md` 230~289행, 시나리오 S3(439~455행).
공통 상수·반올림·타입은 [`diet-domain`](../diet-domain/SKILL.md)을 따른다.

**"운동했으니 더 먹어도 되나?"에 답하는 기능.** 사용자가 한 운동을 기록해 소모 칼로리를 산출하고 그만큼 오늘 목표 칼로리를 늘린다.

## 데이터 모델

`ExerciseEntry`, `MetItem` (→ `diet-domain/references/types.md`), 테이블 `exercise_logs`.
MET 목록은 `src/data/met.json` — 내용은 [`references/met-table.md`](references/met-table.md).

## 입력 — 두 경로

| 경로 | 입력 항목 | `source` |
|---|---|---|
| ① 운동 선택 | 운동 종류, 지속 시간(분) | `'met'` — MET 공식으로 자동 계산 |
| ② 직접 입력 | 운동 이름, 소모 칼로리, 유형 | `'manual'` — 목록에 없는 운동, 기구 표시값 |

공통 입력: 운동 시각(기본값 현재), 날짜(기본값 오늘).

> **경로 ③ 외부 연동(스마트워치·건강앱)은 1차 배포에서 구현하지 않는다** (미결정 #4). 웹앱에서는 접근이 제한적이다. 기기에 표시된 값은 경로 ②로 흡수한다. 명세 240·285~286행의 연동 관련 항목은 지금 구현 대상이 아니다 — 누락이 아니라 보류다.

## 처리

```
① 소모 칼로리 (경로 ①)
   소모 kcal = round(MET × 체중(kg) × 분 ÷ 60)
   체중은 F1 프로필 값. 기록 시점 체중을 weightSnapshotKg에 남긴다

② 오늘 목표 갱신
   오늘 목표 = 기본 목표 + 오늘 운동 소모 합계        (100% 반영)

③ 근력운동 시 단백질 하한 상향
   그날 기록에 kind === 'strength' 가 하나라도 있으면
   단백질 하한을 체중 × 1.2g → 체중 × 1.6g 으로 올린다
   (감량기에도 근합성을 위해 단백질을 더 확보해야 한다)
```

**체중 스냅샷을 남기는 이유** — 나중에 프로필 체중이 바뀌어도 과거 운동 기록의 소모 칼로리를 소급 재계산하지 않는다. 지난 날짜의 숫자가 사후에 흔들리면 안 된다.

## 출력

- 오늘의 운동 기록 목록 (운동명, 시간, 소모 칼로리, 유형)
- 오늘 운동 소모 합계
- 갱신된 오늘 목표와 **늘어난 양** — `운동으로 +311 kcal`
- 계산식 노출 — `MET 8.3 × 75kg × 0.5시간 = 311 kcal`
- 근력운동이 있으면 상향된 단백질 목표

## 확정 UI 문구

- 추정치 안내 (**식단 목표가 다이어트일 때 노출**) —
  *"소모 칼로리는 추정치예요. 다이어트 중이라면 늘어난 만큼 전부 채우기보다 절반 정도만 채우는 걸 권해요."*
- 일상 활동 중복 안내 — *"출퇴근 도보 같은 일상 활동은 이미 활동 수준에 포함되어 있어요. 따로 기록하면 두 번 세게 됩니다."*
- 이상치 확인 — *"오늘 소모 칼로리가 기본 목표보다 많아요. 입력이 맞는지 확인해주세요."*

## 검증·엣지케이스

- **소모 칼로리는 추정치다.** MET 공식은 개인차(체력·근육량·심박)를 반영하지 못해 실제보다 높게 나올 수 있다. 이 사실을 UI에 명시한다
- 기록을 **수정·삭제하면 오늘 목표를 즉시 재계산**한다. 이미 그만큼 먹은 뒤 삭제해 잔여가 음수로 돌아서는 것은 **정상 동작**이다. 막지 않는다
- 일상 활동(출퇴근 도보 등)은 이미 F1 활동계수에 포함 → 중복 기록하지 않도록 안내
- 하루 소모 합계가 **기본 목표의 100%를 초과**하면 입력 오류 가능성 확인 문구를 띄운다 (막지는 않는다)
- 지속 시간 0 이하 또는 480분 초과 → 재확인
- 같은 날 시간대가 겹치는 기록 → 중복 여부 확인 후 저장
- 미래 날짜 거부
- **F1 미완료면 MET 경로를 막는다.** 체중이 없어 계산할 수 없다. 경로 ②(직접 입력)만 연다
- 목록에 없는 운동에 **MET를 임의로 지어내지 않는다.** 유사 종목을 제시하거나 경로 ②로 유도

## 완료 판정

S3 — 75kg 사용자가 조깅 30분 기록 →

- `MET 8.3 × 75kg × 0.5시간 = 311 kcal`
- `기본 목표 1,581 + 운동 311 = 오늘 목표 1,892 kcal`, `운동으로 +311 kcal` 표시
- 잔여가 1,161 → **1,472 kcal**
- 오늘 목표 1,892가 BMR 1,699를 넘었으므로 **"기초대사량보다 낮아요" 경고가 사라진다**
- 추정치 안내 문구 노출

이어서 웨이트(보통 강도) 기록 → 단백질 목표 119g → **120g**, 탄수 158g → **157g**.
그 뒤 조깅 기록 삭제 → 오늘 목표·잔여·단백질 하한이 전부 원복.
